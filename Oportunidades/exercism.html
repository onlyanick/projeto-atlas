Programa

O Exercism é uma plataforma de prática de programação gratuita, de código aberto e mantida por uma organização sem fins lucrativos. O objetivo é ajudar o aluno a ganhar fluência em linguagens de programação por meio de exercícios, conceitos explicados passo a passo e feedback de pessoas mais experientes.

A plataforma reúne exercícios organizados em trilhas, uma para cada linguagem, com mais de 65 linguagens disponíveis, de opções populares como Python, JavaScript, Java e C# a linguagens menos comuns como Elixir, Haskell, Gleam e Rust. Em cada trilha, o aluno aprende os conceitos principais da linguagem e depois resolve exercícios práticos, que podem ser feitos no editor do próprio site ou no computador, usando a interface de linha de comando (CLI).

Além disso a plataforma oferece mentoria: voluntários experientes analisam as soluções enviadas e dão retorno sobre clareza, estilo e boas práticas, ajudando o aluno a escrever código melhor e a pensar como desenvolvedor. A plataforma foi criada por Katrina Owen, é mantida por centenas de colaboradores voluntários e também oferece o Jiki, um curso de fundamentos para quem está começando do zero, além de desafios temáticos como o "12 in 23", que propôs aprender o básico de uma linguagem diferente por mês.

Nota da desenvolvedora

Esse é provavelmente meu site favorito para aprender programação. Além de ter conteúdo até de linguagens mais obscuras, tem boas explicações mas não perde tempo nelas e faz logo o usuário aprender na prática. A comunidade e mentoria também são incríveis.

Trilhas disponíveis

  • Jiki (Fundamentos de Programação)

    O Jiki é o curso de fundamentos do Exercism, voltado para quem nunca programou. Ele apresenta lógica e código de forma guiada e interativa, preparando o aluno para aprender qualquer uma das linguagens da plataforma.

  • Python

    Conhecida pela sintaxe limpa e fácil de ler, Python é uma das linguagens mais usadas do mundo e aparece em automação, ciência de dados, inteligência artificial e desenvolvimento web.

  • JavaScript

    JavaScript é a linguagem da web: roda em todos os navegadores e, com o Node.js, também no servidor. É a base do desenvolvimento front-end e muito usada em aplicações full-stack.

  • Go

    Go é uma linguagem compilada e de tipagem estática, criada no Google e lançada como código aberto em 2009. Tem sintaxe enxuta, compilação rápida e suporte nativo à concorrência, e é muito usada em back-end, computação em nuvem e infraestrutura.

  • Rust

    Rust é uma linguagem de sistemas que garante segurança de memória sem precisar de coletor de lixo, sendo usada em software de baixo nível, ferramentas de linha de comando e WebAssembly.

  • Elixir

    Elixir é uma linguagem funcional que é focada em concorrência e tolerância a falhas, e por isso é muito usada em sistemas distribuídos e aplicações web em tempo real.
